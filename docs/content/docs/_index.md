clai is an AI agent harness written in Clojure. The agent and the developer
share one live JVM: the same process serves the web UI, holds your REPL, and
evaluates the code the agent writes.

Start with [Getting Started](/docs/guides/getting-started/), then read
[Using the REPL](/docs/guides/using-the-repl/) for the part that makes clai
different.
