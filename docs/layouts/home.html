Welcome to clai!

clai is a Clojure AI agent harness where the agent and you share one live JVM.

Prompt from the REPL

new!, prompt! and resume! drive a session directly, and every helper is an ordinary Clojure function you can compose.

One runtime for you and the model

The agent's most powerful tool, eval_clojure, evaluates in the same process as your REPL and the web UI — so a fix you make is live for the agent's next call.

Tools are Clojure values

A tool is a map of {:id :handler :spec}. Registries are immutable maps owned per agent, and adding a tool is assoc.
